# 班級結業分析師：使用者需求、回饋與迭代修正全紀錄 (Changelog)

本手冊詳盡收錄專案自啟動以來，使用者（教育培訓主管/講師）所提出之**所有核心要求、反饋痛點、操作疑問與系統對應修復歷程**，作為未來維護、升級與移交的基準。

---

## 一、 核心功能與初期產品需求

### 1. 雙端架構核心目標
* **學員填答端（手機優先）**：
  * 只需 90 秒即可極速填答完畢。
  * 支援 LINE 直接點開連結，介面友善直覺。
  * 題目涵蓋：起點背景、核心卡關障礙點、講師/助教評分（1~5★）、NPS 淨推薦度（0~10）、質化建議。
  * **單元課兌換機制**：填寫末端可免費自選一門專屬線上單元課，提交後自動生成感謝頁，引導聯繫客服或班主任開通。
* **管理端後台（視覺化多代理人儀表板）**：
  * 提供多代理協同分析指標（量化評分、NPS、質化情緒、交叉歸因）。
  * 單元課兌換名冊：呈現學員姓名、電話、LINE ID、自選課程，支援一鍵複製，保護個資。
  * 結業審查診斷報告書：自動生成專業 HTML/Markdown 報告，可直接列印或轉存 PDF。

### 2. 多班級與課綱自適應（重大架構需求）
* **使用者痛點**：不可寫死單一課程（如僅能支援 2D 動畫班）。
* **實作解法**：
  * 開發「多班級管理中心」，支援切換不同班級，各班級問卷資料庫與報表完全隔離。
  * 開發「AI 課綱智慧解析」功能：支援貼上課程大綱或上傳 PDF 課綱，由 AI 自動提取課程名稱、講師、章節單元、卡關痛點選項與加贈單元課清單，自動建立全新班級問卷。

## 二、 運行中的關鍵問題與使用者回饋（重要修正歷程）

### 1. 學員填答後，後台資料未即時跳出
* **使用者原話**：「*出事了，我請同事填寫完，後台卻沒有跳出來資料～ 他不能自動就同步嗎？*」
* **問題根本原因**：
  * 學員使用雲端網址（Render）填寫問卷，資料儲存在雲端伺服器；本地電腦（Localhost）後台未主動與雲端伺服器建立定時同步機制。
* **修復方案**：
  * 在後台管理端實作自動同步輪詢機制（`/api/sync-responses`，每 10 秒自動觸發），本機與雲端建立雙向即時數據同步。
  * 後台增加「即時同步中」狀態指示燈與手動「立即同步」按鈕，學員一填寫完，後台無感秒級刷新。

---

### 2. 結業診斷報告靜態死板問題（拒絕假資料、拒絕固定範本）
* **使用者原話**：「*我想確認最後一個診斷報告，這個可以依據學員給出的回饋自動更新去做調整嗎？我看內容好像都是固定的？ 包含學員金句牆的內容（目前根本沒有回饋，但卻一些範例？應該是要有的並且系統塞選過適合當金句，再放上去才對），教學覆盤與行動矩陣 這個欄位應該也是要對應到學員填寫完後給出的回饋去做調整修正才對。我現在的版本不是測試版了，而是一個完整，且功能性都是我要的這種版本！*」
* **問題根本原因**：
  * 初期版本為展示效果預先填充了範例金句與固定行動矩陣，即使無資料或不同班級也顯示相同文字。
* **修復方案**：
  * **真數據驅動**：徹底移除所有靜態 Mock 文字！
  * **學員金句牆（Quote Wall）**：
    * 無學員文字回饋時，優雅顯示「暫無文字評語，等待學員提交金句回饋」。
    * 有填答時，由文字情緒分析代理人（Agent 3）動態篩選出高價值正向推薦金句、建設性建議，動態掛載至金句牆。
  * **教學覆盤與行動矩陣（Action Matrix）**：
    * 對應學員填答之最高頻卡關痛點、不同起點滿意度落差，由教學策略代理人（Agent 5）動態運算產出「即刻速贏（Quick Wins）」、「次期優化（Next Term）」、「長期架構（Long-term Strategy）」。
  * **HTML/PDF 診斷報告**：完全根據即時運算之 `SurveyAnalysisState` 動態組裝生成。

### 3. Agent 7 諮詢顧問問答生硬、限制關鍵字問題
* **使用者原話**：「*已支援精準識別：LINE 致詞文案、學員卡關點深度剖析、下一期招生與轉化建言、助教服務評鑑、整體教學亮點彙整。我發現他只能這些精準識別的字句完全正確才會編列出回應。*」
* **問題根本原因**：
  * 早期本地版本僅採用簡單正則關鍵字匹配，用戶若稍微換個問法（或口語發問），系統就無法理解。
* **修復方案**：
  * 全面接入 Google 官方 Gemini 大語言模型 API，轉為 ChatGPT 般的開放式智慧問答。
  * 系統提示詞（System Prompt）注入整份班級結業問卷的統計總覽、講師均分、NPS、核心痛點與金句摘要，讓大模型能根據全盤脈絡回答任何自由提問。

### 4. Gemini API Key 安全性與 Render 配置疑問
* **使用者原話**：「*我沒有 Gemini API Key，教我申請*」；配置後在 Render 詢問「*哪*」。
* **問題根本原因**：
  * 用戶未接觸過 Google AI Studio 金鑰申請流程；且 GitHub 安全防護會封鎖包含 API Key 的程式碼上傳。
  * 用戶在 Render 專案總覽頁面找不到在哪裡輸入環境變數。
* **修復與引導方案**：
  * 提供申請步驟與 Google AI Studio 直達連結。
  * 建立安全防護：API Key 僅存於本機 `.env`（加入 `.gitignore`），絕不提交至版本庫。
  * 圖文引導 Render 後台路徑：`My project` ➜ `dawei-survey (Web Service)` ➜ 左側 `Environment` ➜ `Add Environment Variable`（Key: `GEMINI_API_KEY`）➜ `Save Changes`。

### 5. 後台登入失敗（401 Unauthorized）
* **使用者原話**：「*無法登入耶*」
* **問題根本原因**：
  * 在安全重構環境變數讀取邏輯時，`config.py` 不慎遺漏了 `ADMIN_PASSWORD = os.getenv("ADMIN_PASSWORD", "art888")`，導致 Basic Auth 驗證時擲出 AttributeError。
* **修復方案**：
  * 補回 `ADMIN_PASSWORD` 預設值與環境變數對應，重啟服務，恢復 `admin` / `art888` 登入。

---

### 6. AI 回答奇怪、死板（出現固定罐頭文字）
* **使用者原話**：「*他回答得非常奇怪很不ai*」（問題：給我一個明天停課一次的講稿 50字內，卻回傳「經多代理協同分析，本期課程整體滿意度與 NPS 表現良好...」）
* **使用者二次原話**：「*回答又是很怪的*」（問題：中秋節要祝賀班級同學的文案 50字內，卻回傳「Zorioz 給【2D動畫設計班】全體學員的結業致謝信」）
* **問題根本原因（深度排查結果）**：
  1. **Google 免費層 Quota 限制（HTTP 429）**：Google AI Studio 新申請的金鑰在頂規 `Gemini 3.7 Flash` 模型上極易觸發每分鐘請求上限（429 錯誤），而 `Gemini 3.6 Flash` 則在 Google 節點出現讀取超時。
  2. **保底機制觸發連鎖誤判**：
     * 當 API 呼叫失敗時，系統啟動本地保底。舊保底邏輯將「祝賀」、「文案」等同於「結業信」，導致無論問中秋節或停課，都硬吐出固定範本。
* **修復方案**：
  1. **主力模型更換為 `gemini-3.5-flash-lite`**：免費用戶額度超大、回應速度小於 0.8 秒、完全不觸發 429 錯誤。
  2. **建立多模型智慧容錯輪詢鏈**：`[gemini-3.5-flash-lite -> gemini-3.5-flash -> gemini-3.7-flash]`，任何單一模型滿載時自動無感切換備用模型。
  3. **精準拆分離線保底庫**：獨立節慶祝賀（中秋、端午、連假）、調課停課通知與結業致詞，絕不張冠李戴。

### 7. 跨裝置使用與遠端電腦無法登入
* **使用者原話**：「*我想確認，這個網站後台是只能我這台電腦使用嗎？ 我用別的電腦登入都無法。 可以解決這個問題嗎？我有時候在不同地方會使用的不同電腦操作*」
* **問題根本原因**：
  * 在其他電腦上誤輸入了 `http://localhost:8080/admin`（`localhost` 僅代表當前本機電腦）。
  * 未使用已部署的全球公開雲端網址，或未了解 Render 免費實例的喚醒時間（約 30~50 秒）。
* **修復與指引方案**：
  * 說明 `localhost` 與 `onrender.com` 之差別。
  * 提供全球通用網址：`https://dawei-survey.onrender.com/admin`，登入帳號 `admin` / 密碼 `art888`，支援全球任何電腦、手機隨時登入。

### 8. 班級選單增加刪除功能 (Class Deletion)
* **使用者原話**：「*課程下拉選單內，我想要有可以刪除的功能。*」
* **實作與安全機制**：
  1. **頂部選單即時刪除**：在頂部班級下拉選單右側新增醒目的 `🗑️ 刪除此班級` 按鈕，選定任何班級後可一鍵刪除。
  2. **班級管理卡片刪除**：在「班級與問卷文案自訂編輯」的已發布班級清單中，每個班級卡片亦配置專屬 `🗑️ 刪除班級` 按鈕。
  3. **二次確認防誤觸機制**：彈出確認警告對話框，明確提示專屬問卷失效與資料連帶清理。
  4. **後端資料安全防護**：
     * 實作 `/api/delete-class` API（受管理員密碼保護）。
     * 至少需保留一個班級，防止清空資料庫。
     * 若刪除當前活躍班級，系統自動切換至剩餘的第一個班級，並同步清理該班級在 CSV 中的填答資料，杜絕孤兒數據殘留。

### 9. 完課好禮課程贈送開關（行銷活動啟閉 ✕ 純回饋免選課直接送出）
* **使用者原話**：「*在雲端正式後台 放置一個 我要不要贈送好禮課程的選項。有時候我想要行銷時我在打開 不需要時關閉，他們填寫完回饋就可以送出這樣*」
* **實作與架構設計**：
  1. **雲端正式後台醒目開關**：
     * **頂部常駐資訊列**：新增好禮贈送模式按鈕：`🎁 好禮課程：[ 啟用中 (行銷模式) / 已關閉 (純回饋模式) ]`，點擊即可一秒無感切換，即時更新。
     * **班級編輯分頁**：新增「11. 完課好禮課程贈送開關」選單，方便在編輯課名文案時同步調整設定。
     * **已建立班級清單**：每個班級卡片直觀標示「🎁 好禮贈送中」或「📝 純回饋模式」狀態徽章，並提供切換按鈕。
  2. **學員填答端（問卷）極簡體驗**：
     * **開啟時（行銷模式）**：問卷顯示頂部好禮橫幅、Q11 好禮兌換意願、第 05 區單元課任選及專員聯繫資訊，送出後登記領獎。
     * **關閉時（純回饋模式）**：問卷自動隱藏頂部好禮橫幅、隱藏 Q11、隱藏第 05 區單元課與電話個資欄位；提交按鈕自動改為「🚀 送出結業回饋問卷」，填完滿意度即可一鍵直接送出，填答零門檻、完填率倍增！
  3. **後端資料與 API 支援**：
     * 班級資料結構全面新增 `enable_gift: bool` 屬性。
     * 建立受管理員保護之 `/api/toggle-gift` 與 `/api/update-class` 支援。
     * `/api/submit` 自動放寬驗證，純回饋填答安全儲存為「無需兌換 (純回饋)」。
