## 各代理人詳細職責與資料規格

### 1. Agent 1：問卷資料檢驗員 (Data Inspector)
* **輸入**：學員填答 DataFrame (`raw_responses`)。
* **輸出至 State**：`inspection_summary`。
* **處理項目**：
  * 計算總回收有效問卷數、各題填答完整率。
  * 審查離群值（如文字過短、全選最高/最低分異常填答）。
  * 產生資料健康度評級（A+/A/B）。

### 2. Agent 2：量化滿意度與 NPS 評鑑員 (Quantitative & NPS Analyst)
* **輸入**：檢驗合格之量化欄位。
* **輸出至 State**：`quant_metrics`。
* **處理項目**：
  * 授課講師教學滿意度均分（1~5★）與標準差。
  * 助教課堂與作業支援均分（1~5★）與標準差。
  * 淨推薦值 NPS 計算：
    $$\text{NPS} = \% \text{推薦者 (9-10分)} - \% \text{批評者 (0-6分)}$$
  * 輸出淨推薦值（範圍 -100 ~ +100）及推薦/中立/批評者百分比。

### 3. Agent 3：質化情緒與學員金句萃取師 (Text Sentiment Analyst)
* **重大規範**：**嚴禁使用死板靜態文字！**
* **無填答時**：明確標註「等待學員提交金句回饋」，不展示 Mock 資料。
* **有填答時**：
  * 動態萃取學員正向讚賞與教學亮點，掛載至後台「**學員金句牆（Quote Wall）**」。
  * 動態篩選建設性改進意見與學員挫折反饋，歸入「**待改善與預警清單（Alerts）**」。

### 4. Agent 4：起點與卡關點交叉歸因分析師 (Correlation Analyst)
* **輸入**：學員起點自述（零基礎、有經驗、職業從業者） ✕ 核心卡關點單選/多選。
* **輸出至 State**：`cross_correlations`。
* **處理項目**：
  * 計算不同基礎學員在各單元節奏、技巧吸收的落差。
  * 輸出關鍵教學因果關聯（例如：「零基礎學員主要卡在正片疊底色階，而進階學員更渴望商業實戰」）。

### 5. Agent 5：教學行動策略師 (Pedagogical Strategist)
* **重大規範**：行動矩陣必須緊密掛鉤 Agent 2, 3, 4 所產出的真實數據。
* **輸出矩陣（Action Matrix）**：
  1. **即刻速贏（Quick Wins - 24H內）**：針對學員第一名卡關點，下期上課前提供參數口訣或預習包。
  2. **次期優化（Next Term - 課綱調整）**：針對滿意度較薄弱章節微調示範節奏與操作停頓。
  3. **長期架構（Long-term Strategy - 商業續報）**：根據高滿意度口碑，推動學員轉化報名進階商業實戰班。

### 6. Agent 6：結業審查報告書總協調員 (Chief Synthesizer & Auditor)
* **輸出至 State**：`final_report_md`、`final_report.html`。
* **處理項目**：
  * 匯聚前 5 大代理人之全盤數據，自動編撰成具備專業教育評估標準之「結業診斷報告書」。
  * 前端後台支援一鍵列印（`window.print()`）或儲存為 PDF，排版針對 A4 列印做過專門 CSS 優化。

### 7. Agent 7：問卷即席諮詢顧問 (Chat Advisor)
* **架構**：大語言模型優先（Live LLM First） ✕ 毫秒級容錯備援鏈。
* **主力模型**：`gemini-3.5-flash-lite`（極速、免費用戶額度超大、零 429 報錯）。
* **備援模型鏈**：`[gemini-3.5-flash-lite ➜ gemini-3.5-flash ➜ gemini-3.7-flash]`。
* **動態 Context 注入**：將當前班級之填答規模、講師均分、NPS、痛點摘要與精華金句作為背景，使 AI 回答具備全域脈絡。
